# 厦门招聘数据清洗与分析报告

## 一、项目背景与目标
# 厦门招聘市场数据清洗与分析

## 项目背景

厦门是福建省经济中心，也是东南沿海重要的港口城市。
随着就业市场日益活跃，求职者和企业都需要了解"厦门招聘市场的真实情况"——
哪些行业在招人？薪资水平如何？学历和经验要求有多高？

## 数据来源

- **来源**：数据来自公开的招聘数据集，覆盖厦门地区 10 万条招聘信息
- **规模**：100,031 条招聘信息，19 个字段
- **字段**：岗位名称、公司名称、薪资、学历要求、经验要求、
  工作地址、福利待遇、公司类型、行业领域等
- **时间**：2026 年

## 项目目标

本项目旨在回答以下 6 个问题：

1. **市场概览**：厦门招聘市场的平均薪资、工时、学历要求分布如何？
2. **学历 vs 薪资**：学历越高，薪资越高吗？大专到本科的"跳变"有多大？
3. **经验 vs 薪资**：经验值多少钱？几年经验是"分水岭"？
4. **行业 vs 薪资**：哪些行业招人最多？哪些行业薪资最高？
5. **区域 vs 薪资**：厦门哪个区招聘最多？哪个区薪资最高？
6. **公司类型 vs 薪资**：国企、外企、民企、上市公司，谁的薪资高？

## 二、数据清洗与预处理

### 1. 招聘人数（recruit_num）

**处理逻辑：**

- **标记模糊需求**：创建 `is_vague` 标记列。将“若干”和缺失值统一标记为“需求模糊”（1），保留原始数据的可追溯性。
- **数值填充**：用非模糊岗位招聘人数的**中位数**进行填充，避免直接填1造成的低估偏差。
- **异常值处理**：使用 **IQR 四分位距法**识别极端高值，采用**盖帽法**将超过上限的数据压至合理范围。
- **格式转换**：统一转换为整数类型，便于后续聚合计算。

**数据局限性：**

- 中位数填充虽能保留样本，但可能仍会**轻微低估**头部大厂的真实招聘总量。
- 盖帽法平滑了极端值，可能会弱化部分大厂“大扩招”的真实招聘规模。后续分析会结合 `is_vague` 标签进行交叉验证。

### 2. 工作类型（work_type）

**处理逻辑：**
- **数据诊断**：用 `unique()` 查看原始取值，发现共有 5 种类型（全职、实习、兼职、毕业生见习、临时），且无缺失值。
- **业务归并**：结合招聘业务语义，将含义重叠的类别进行合并：“毕业生见习”属于实习性质，“临时”属于兼职性质，统一归并为 **全职、实习、兼职** 三大类。
- **生成标准化列**：新建 `work_type_std` 列存储清洗后的结果，保留原始 `work_type` 列以便追溯。

**数据结果：**
- 全职：98,352 条（约 98.3%）
- 兼职：880 条（约 0.9%）
- 实习：799 条（约 0.8%）

**分析建议：**
- 厦门招聘市场以全职岗位为绝对主导，兼职和实习占比极低。
- 因兼职和实习样本量过小，后续进行薪资、学历等交叉分析时，需警惕小样本带来的波动偏差，必要时可剔除后单独分析全职市场。
